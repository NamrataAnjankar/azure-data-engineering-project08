# End-to-End Azure Data Engineering Project

## Overview

This project demonstrates an end-to-end Azure data engineering workflow using Azure cloud services.

The project includes:
- Data ingestion using Azure Data Factory
- Cloud storage integration
- Data transformation using Databricks and PySpark
- KPI generation using Spark SQL
- Dashboard reporting using Power BI

---

# Technologies Used

- Azure Data Factory
- Azure Databricks
- PySpark
- Spark SQL
- Azure Blob Storage
- SQL Server
- Power BI
